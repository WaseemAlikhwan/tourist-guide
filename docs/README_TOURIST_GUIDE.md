# 🌍 نظام الدليل السياحي المتقدم
## Tourist Guide Advanced System

نظام متكامل لإدارة الوجهات السياحية والأنشطة مع ميزات متقدمة للحجز والتخطيط.

---

## 🎯 الميزات الرئيسية

### 1. **نظام الحجز الذكي** 📅
- حجز الأنشطة السياحية بسهولة
- نظام مراجع الحجز الفريدة
- حالات متعددة للحجز (قيد الانتظار، مؤكد، ملغي، مكتمل)
- إضافة طلبات خاصة مع كل حجز
- التحقق الفوري من صحة الكوبونات

### 2. **مخطط الرحلات الذكي** 🗓️
- إنشاء جداول زمنية مفصلة للرحلات
- إضافة وجهات وأنشطة لكل يوم
- تحديد الأوقات والملاحظات لكل نشاط
- مشاركة جداول الرحلات مع الآخرين (عامة/خاصة)
- حساب تلقائي لمدة الرحلة والميزانية المقدرة

### 3. **نظام النقاط والمكافآت** 🏆
- كسب نقاط من كل حجز وتقييم
- 4 مستويات عضوية (برونزي، فضي، ذهبي، بلاتيني)
- مزايا متدرجة حسب المستوى
- سجل كامل لجميع النقاط المكتسبة والمستخدمة
- ترقية تلقائية للمستويات

#### مزايا المستويات:
- **برونزي (0-1999 نقطة):**
  - خصم 5% على جميع الحجوزات
  - نقاط مكافأة على كل حجز

- **فضي (2000-4999 نقطة):**
  - خصم 10% على جميع الحجوزات
  - نقاط مكافأة مضاعفة
  - أولوية في خدمة العملاء

- **ذهبي (5000-9999 نقطة):**
  - خصم 15% على جميع الحجوزات
  - نقاط مكافأة ثلاثية
  - وصول مبكر للعروض الخاصة
  - إلغاء مجاني للحجوزات

- **بلاتيني (10000+ نقطة):**
  - خصم 20% على جميع الحجوزات
  - نقاط مكافأة رباعية
  - مدير حساب شخصي
  - ترقيات مجانية
  - هدايا حصرية

### 4. **نظام الشارات والإنجازات** 🎖️
تُمنح الشارات تلقائياً عند تحقيق إنجازات معينة:
- 🗺️ **مستكشف مبتدئ** - أول حجز
- ✈️ **محب السفر** - 5 أنشطة محجوزة
- 📋 **مخطط رحلات** - إنشاء أول جدول رحلة
- ⭐ **ناقد محترف** - كتابة 10 تقييمات
- 🏆 **جامع الوجهات** - 20 وجهة في المفضلة
- 🌍 **مستكشف العالم** - زيارة 10 دول
- 🥈 **عضو فضي** - الوصول للمستوى الفضي
- 🥇 **عضو ذهبي** - الوصول للمستوى الذهبي
- 💎 **عضو بلاتيني** - الوصول للمستوى البلاتيني
- 🎟️ **صياد الصفقات** - استخدام 5 كوبونات

### 5. **نظام الكوبونات والخصومات** 🎫
- كوبونات بنسبة مئوية أو قيمة ثابتة
- حد أدنى للشراء
- حد أقصى للاستخدام
- فترة صلاحية محددة
- تفعيل/تعطيل مرن
- تتبع استخدام الكوبونات

### 6. **معرض الصور المتعدد** 📸
- رفع صور متعددة لكل وجهة ونشاط
- ترتيب الصور حسب الأولوية
- إضافة توضيحات للصور
- تحديد صور مميزة
- إدارة سهلة من لوحة التحكم

### 7. **نظام الإشعارات** 🔔
- إشعارات تلقائية للحجوزات
- تنبيهات تغيير الحالة
- إشعارات الشارات الجديدة
- تذكيرات الرحلات القادمة

### 8. **الميزات الأساسية** ⭐
- إدارة الوجهات السياحية
- إدارة الأنشطة السياحية
- نظام التقييمات والمراجعات
- نظام المفضلة
- خرائط تفاعلية (إحداثيات GPS)
- لوحة تحكم إدارية متكاملة
- واجهة مستخدم عصرية وسهلة

## 📦 التثبيت والإعداد

### المتطلبات:
- PHP >= 8.1
- Composer
- MySQL/MariaDB
- Node.js & NPM

### خطوات التثبيت:

```bash
# 1. تثبيت المكتبات
composer install
npm install

# 2. نسخ ملف البيئة
cp .env.example .env

# 3. توليد مفتاح التطبيق
php artisan key:generate

# 4. إعداد قاعدة البيانات في ملف .env
DB_DATABASE=tourist_guide
DB_USERNAME=root
DB_PASSWORD=

# 5. تشغيل الترحيلات
php artisan migrate

# 6. تشغيل البيانات الأولية
php artisan db:seed --class=AdminSeeder
php artisan db:seed --class=BadgeSeeder
php artisan db:seed --class=CouponSeeder

# 7. إنشاء رابط التخزين
php artisan storage:link

# 8. بناء الأصول
npm run build

# 9. تشغيل السيرفر
php artisan serve
```

## 🔄 API Routes

### User Routes:
```
GET    /                           - الصفحة الرئيسية
GET    /destinations               - قائمة الوجهات
GET    /activities                 - قائمة الأنشطة
GET    /bookings                   - حجوزاتي
POST   /bookings/{activity}/book   - حجز نشاط
GET    /itineraries                - جداول الرحلات
POST   /itineraries                - إنشاء جدول رحلة
GET    /loyalty                    - النقاط والمكافآت
GET    /favorites                  - المفضلة
```

### Admin Routes:
```
GET    /admin/dashboard            - لوحة التحكم
CRUD   /admin/destinations         - إدارة الوجهات
CRUD   /admin/activities           - إدارة الأنشطة
CRUD   /admin/bookings             - إدارة الحجوزات
CRUD   /admin/coupons              - إدارة الكوبونات
CRUD   /admin/badges               - إدارة الشارات
CRUD   /admin/gallery              - إدارة المعرض
```
